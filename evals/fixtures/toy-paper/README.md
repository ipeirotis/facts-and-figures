# toy-paper

A synthetic paper repository used as the facts-and-figures eval fixture:
a manuscript, its dataset, and a deterministic analysis pipeline
(`python3 analysis/run_analysis.py`, stdlib only, writes
`results/results.json`).

The eval harness, and what this fixture is designed to exercise, are
documented in `../../README.md`. Do not copy the harness or its answer key
into a workspace where an agent is being evaluated.
